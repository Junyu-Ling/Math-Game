# RAPFI Gomoku engine (optional)

Place a Gomocup-compatible **RAPFI** binary here so the site CPU can use it:

- `pbrain-rapfi.exe` (Windows) or `pbrain-rapfi` (Linux/macOS)

Download: https://github.com/dhbloo/rapfi/releases (`Rapfi-engine.7z`)

Or set `RAPFI_PATH` in `server/.env` to the full path of the binary.

Without RAPFI, Gomoku falls back to the built-in JS AI.
